# SNOMED CT translations for CH EMS

Result of the terminology review for [issue #69](https://github.com/hl7ch/ch-ems/issues/69).

* Source: SNOMED CT Swiss Edition, version 20260607, from tx.fhir.ch
* German rules: [D-A-CH translation guideline](https://conf.spaces.snomed.org/wiki/spaces/GTG/pages/132539391) (current version; the page linked in the issue is no longer maintained)
* French rules: [editorial guide v2.29](https://conf.spaces.snomed.org/wiki/spaces/FTCG/pages/131338809/Documentation)
* Italian: follows the French rules, as stated in the issue
* All 177 SNOMED CT concepts of the IG were checked: 144 in the value sets, 33 only in profiles or examples

**The translations in section 1 are proposals. They still need a review by IVR and by native speakers, especially the Italian terms.**

## 2. Decisions for IVR

### 2.1 Label does not match the concept

A Swiss Edition term would change what users see and record, so the IVR label stays and only its form was fixed. The section 1 proposal is a translation of the concept, not of this label. Changing the code is a decision for IVR.

| Concept | IG label (DE) | Problem | Possible code |
|---|---|---|---|
